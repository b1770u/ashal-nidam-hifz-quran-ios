# أسهل نظام لحفظ القرآن — iPhone / iPad

نسخة iOS من تطبيق [أسهل نظام لحفظ القرآن](https://github.com/b1770u/ashal-nidam-hifz-quran-apk) (نفس واجهة تطبيق الأندرويد حرفياً).

## التحميل
⬇️ **[آخر إصدار (ملف ‎.ipa)](../../releases/latest)**

التطبيق غير منشور على App Store بعد، لذلك يُثبَّت عبر **Sideloadly** أو **AltStore** بحساب Apple ID (مجاني، مع إعادة التوقيع كل 7 أيام).

## كيف بُني
- الواجهة: `www/` — منسوخة من مشروع الأندرويد بـ `./sync-web.sh` (نفس `index.html`) مع ملفي `ios-bridge.js` و `ios-post.js` اللذين يوفّران نفس واجهة `AndroidBridge`.
- الخصائص الأصلية (Swift): `native/quran-native/` — التلاوة في الخلفية وعلى شاشة القفل، التذكير اليومي بأزرار، التعرف على الكلام بالعربية، التحميل بدون إنترنت، النسخة الاحتياطية، المشاركة.
- البناء والاختبار: GitHub Actions على macOS (`.github/workflows/ios.yml`) — يبني التطبيق، يجرّبه على محاكي iPhone و iPad ويأخذ صوراً، ويُخرج ملف ‎.ipa غير موقّع. وسم `vX.Y.Z` ينشر إصداراً.
